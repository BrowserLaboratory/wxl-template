## Why

專案的 `README.md` 與 `CONTRIBUTE.md` 目前為空白，使外部貢獻者無法了解專案目的、架構與協作流程，不符合開源社群的基本期待。補齊這兩份文件能讓新貢獻者快速上手，也能提升專案的可信度與可維護性。

## What Changes

- 撰寫 `README.md`：含專案簡介、技術架構、安裝與開發流程、badge 等 OSS 標準內容
- 撰寫 `CONTRIBUTE.md`：說明 git flow 分支模型、PR 流程、Commit 規範、Issue 回報方式

## Capabilities

### New Capabilities

- `oss-readme`: 符合 OSS 標準的 README 文件，涵蓋專案描述、技術棧、環境需求、快速開始、架構說明
- `contributor-guide`: 貢獻者指南，說明 git flow 工作流程、PR 提交規範、Commit message 格式、Issue 模板使用方式

### Modified Capabilities

（none）

## Impact

- Affected specs: 無現有 spec 異動
- Affected code:
  - `README.md`
  - `CONTRIBUTE.md`
